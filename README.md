# Typescript-Practice

A personal sandbox for practicing TypeScript — small exercises, language features, and experiments.

## Getting started

```bash
npm install
```

## Layout

Each exercise lives in its own file or folder under `src/`. Nothing here depends on anything else, so files can be added, changed, or deleted freely.

## Running a file

With [tsx](https://github.com/privatenumber/tsx) (no build step):

```bash
npx tsx src/example.ts
```

Or compile with the TypeScript compiler and run the output:

```bash
npx tsc
node dist/example.js
```
